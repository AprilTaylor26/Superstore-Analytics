# Superstore-Analytics
This project contains a Tableau workbook built using the Superstore dataset to explore retail performance across geography, product categories, and customer segments.

Features:
---
Profit Ratio by Geography: State‑level profitability visualization using generated latitude/longitude fields.
Sales by Category: Stacked area chart showing monthly sales trends across Furniture, Office Supplies, and Technology.
Sales by Segment: Time‑series analysis segmented by Consumer, Corporate, and Home Office.
City Profitability: Horizontal bar chart comparing profit ratios across major U.S. cities.
Skills Demonstrated
Tableau dashboard design
Data visualization best practices
Aggregations, filters, and calculated fields
Multi‑sheet dashboard composition

Files Included
Superstore.twb — Tableau workbook
Project_SuperStore.xlsx — dataset used for analysis
